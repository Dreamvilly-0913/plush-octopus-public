# Plush Octopus 项目接续

项目根目录：克隆后的 `plush-octopus-public/`。

这是 Claude Opus 5.5 章鱼毛绒玩偶示例的交互式 Three.js/WebGL2 重制。本公开副本从当前源码快照建立，不包含原仓库的 Git 提交历史；第三方来源与依赖署名保留。

## 启动与构建

```powershell
git clone https://github.com/Dreamvilly-0913/plush-octopus-public.git
cd plush-octopus-public
npm install
npm run dev
npm run build
```

本地开发地址：`http://127.0.0.1:5193/`。源码位于 `src/`，说明见 `README.md`，依赖许可证见 `docs/THIRD_PARTY_NOTICES.md`。
